    createTemplate

    createTemplate: {
        (template: unknown): TemplateFunction;
        (template: unknown, context: unknown, parent?: unknown): Node;
    }

    Type Declaration

      • (template: unknown): TemplateFunction

      • Creates a template. With a context, renders it right away and returns the resulting DOM node. Otherwise, returns a function that can be called with a context (and optionally a parent node to render into) to render it.

        ConstraintJS templates use a syntax like Handlebars. Values in the context can be constraints; the rendered DOM stays up to date as they change.

        Expressions

        <h1>{{title}}</h1>
        <p>{{subtext.toUpperCase() + "!"}}</p>

        With { title: cjs('hello'), subtext: 'world' }, renders <h1>hello</h1><p>WORLD!</p>.

        Use triple braces to insert HTML: <p>{{{html_content}}}</p>

        Comments are ignored: {{! a comment }}

        Events and inputs

        data-cjs-on-(event)=handler calls the context's handler when the event happens:

        <div data-cjs-on-click=update_obj></div>

        data-cjs-out=name sets the context's name to a constraint for the input's value:

        <input data-cjs-out=user_name />
        <h1>Hello, {{user_name}}</h1>

        Block helpers

        Loops

        {{#each}} renders its content for every item of an array or object. {{this}} is the current item, {{@index}} its index, and for objects, {{@key}} its key. The {{#else}} part is rendered when there are no items.

        {{#each arr_name}}
            {{@index}}: {{this}}
        {{#else}}
            <strong>No items!</strong>
        {{/each}}

        Conditions

        {{#if cond1}}
            Cond content
        {{#elif other_cond}}
            other_cond content
        {{#else}}
            else content
        {{/if}}

        The opposite of {{#if}} is {{#unless}}:

        {{#unless logged_in}}
            Not logged in!
        {{/unless}}

        State

        {{#fsm}} renders the content for an FSM's current state:

      • (template: unknown, context: unknown, parent?: unknown): Node

      • Creates a template. With a context, renders it right away and returns the resulting DOM node. Otherwise, returns a function that can be called with a context (and optionally a parent node to render into) to render it.

        ConstraintJS templates use a syntax like Handlebars. Values in the context can be constraints; the rendered DOM stays up to date as they change.

        Expressions

        <h1>{{title}}</h1>
        <p>{{subtext.toUpperCase() + "!"}}</p>

        With { title: cjs('hello'), subtext: 'world' }, renders <h1>hello</h1><p>WORLD!</p>.

        Use triple braces to insert HTML: <p>{{{html_content}}}</p>

        Comments are ignored: {{! a comment }}

        Events and inputs

        data-cjs-on-(event)=handler calls the context's handler when the event happens:

        <div data-cjs-on-click=update_obj></div>

        data-cjs-out=name sets the context's name to a constraint for the input's value:

        <input data-cjs-out=user_name />
        <h1>Hello, {{user_name}}</h1>

        Block helpers

        Loops

        {{#each}} renders its content for every item of an array or object. {{this}} is the current item, {{@index}} its index, and for objects, {{@key}} its key. The {{#else}} part is rendered when there are no items.

        {{#each arr_name}}
            {{@index}}: {{this}}
        {{#else}}
            <strong>No items!</strong>
        {{/each}}

        {{#elif other_cond}}

        {{#else}}
            else content
        {{/if}}
