    Class Constraint<T>

    Note: the preferred way to create a constraint is with cjs(value) or cjs.constraint(value).

    A constraint communicates with the constraint solver to store and maintain a value. Its value can be a plain value, a function that computes it (whose dependencies are tracked automatically), or another constraint to follow.

    Example

    var x = cjs(1),
            y = cjs(function() { return x.get() + 1; });
        y.get(); // 2
        x.set(10);
        y.get(); // 11
